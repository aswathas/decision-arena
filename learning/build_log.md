# Build log - the learner's record

**This file is append-only. Never edit or delete an earlier entry.**

Each session adds one entry. It is written in the *learner's* words, because
the point of the log is not what was done but what the learner now understands.

The engine writes these entries for you:

```bash
python tools/learn_state.py log --lesson L12 \
  --title "Softmax" \
  --summary "I finally see why subtracting the max is allowed" \
  --concept "numerical-stability" \
  --note "Needed the example with the quiz show to click it."
```

A future session reads these notes in the warm-up. Write them for the learner
you are going to be tomorrow.
